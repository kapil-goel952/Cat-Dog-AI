# Dataset Information

## Cats and Dogs Image Dataset

This project uses the Microsoft Cats and Dogs dataset, originally distributed as the Kaggle Cats vs Dogs image collection.

**Original archive:** `kagglecatsanddogs_5340.zip`

**Dataset source:** [Microsoft Download Center](https://www.microsoft.com/en-us/download/details.aspx?id=54765)

### Dataset preparation

The original archive contains approximately 12,500 cat images and 12,500 dog images.

For this project, a subset of valid images was selected:

| Category | Training | Validation |
|---|---:|---:|
| Cats | 1,000 | 500 |
| Dogs | 1,000 | 500 |
| **Total** | **2,000** | **1,000** |

Damaged or unreadable images were excluded during preparation.

The original dataset and prepared image folders are not included in this GitHub repository. Users should obtain the dataset from its original source and follow its applicable licensing terms.
